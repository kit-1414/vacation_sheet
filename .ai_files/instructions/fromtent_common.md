# экранная часть - фронтенд

## правила при создании оаботе фронтенда

### даты и время
Для всех полей даты и времени на фронтенде, которые в составе структур данных отправляются на бэкенд, надо добавлять строгую проверку валидности дат и времени.
Для всех контролов-форм даты и времени добавлять строку подсказку формата - какая цифра что значит.
