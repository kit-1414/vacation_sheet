Приложение учета отпусков

# Введение

Требуется создать микросервисное прилоэение для ведения графика отпусков сотрудников.

# Пользователи системы

Пользователи системы это люди. С назначенными ролями (0 и более)

## Роли в системе

- admin -может выполнять лбюбые сценарии
- Сотрудник
- апрувер (отпусков)

Также в системе можно вести список проектов, в которых участвуют сотрудники (связь многие ко мнгогим)

# Сценарии и процессы

## Основной процесс системы

- сотрудник создает запрос на отпуск
- апрувер смотрит список запроешнных отпусков и апрувит либо отклоняет его

### Сценаарий апрувера

- просмотреть список заявок на отпуска. ФИльтрация по проекту, по диапазону дат, по статусу заявки, по фио пользователя
- заапувить отпск (добавив комментарий в заявку)
- отклонить отпуск (с комментарием в заявке)

## Сценаарий сотрудника

- Зайти на страницу своих заявок.
- Посмотреть список своих заявлений
- Создать новую заявку и отредактировать ее пока статус черновик (Draft).
- Пользователь переводит заявку в статус Готова (Ready).
- Из состояния готово пользователь можно вернуть в статус Черновик.

## Действия админа

- создать-удалить пользователя
- создать-удалить - отредактировать проект
- добавитть удалить-отредактировать сотрудника из проекта (связь многие ко многим).
- Допустимы проекты без сотрудников и сотрудники без проекта
- при удалении проекта удаляется только проект. Сотрудники отсоединяются.
- при удалении сотрудника удаляется сотрудник и его отпуска. Проекты отсоединяется
