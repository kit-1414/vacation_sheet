# Приложение учёта отпусков

# Введение

Требуется создать микросервисное приложение для ведения графика отпусков сотрудников.

# Пользователи системы

Пользователи системы — это люди с назначенными ролями (ноль или более).

## Роли в системе

- admin — может выполнять любые сценарии;
- сотрудник;
- апрувер отпусков.

Также в системе можно вести список проектов, в которых участвуют сотрудники (связь «многие ко многим»).

# Сценарии и процессы

## Основной процесс системы

- сотрудник создаёт запрос на отпуск;
- апрувер просматривает список запрошенных отпусков и одобряет либо отклоняет запрос.

### Сценарий апрувера

- просмотреть список заявок на отпуск с фильтрацией по проекту, диапазону дат, статусу заявки и ФИО пользователя;
- одобрить отпуск, добавив комментарий в заявку;
- отклонить отпуск с комментарием в заявке.

## Сценарий сотрудника

- Зайти на страницу своих заявок.
- Посмотреть список своих заявлений.
- Создать новую заявку и редактировать её, пока она находится в статусе «Черновик» (`Draft`).
- Перевести заявку в статус «Готова» (`Ready`).
- Вернуть заявку из состояния «Готова» в состояние «Черновик».

## Действия админа

- создавать и удалять пользователей;
- создавать, удалять и редактировать проекты;
- добавлять сотрудников в проекты и удалять их из проектов (связь «многие ко многим»).
- Допустимы проекты без сотрудников и сотрудники без проекта.
- При удалении проекта удаляется только проект, а сотрудники отсоединяются.
- При удалении сотрудника удаляются сотрудник и его отпуска, а проекты отсоединяются.

# Архитектура модуля

Система состоит из двух модулей:

- `vacation-sheet-ui` — фронтенд на Angular;
- `vacation-sheet-service` — бэкенд на Spring Boot 3 и Kotlin.
  - Для бэкенда использовать стиль Packaging by Layer.
- Сборку бэкенда организовать мультимодульной, где бэкенд — один из модулей.
  Сборка запускается из корневой папки проекта.

# Авторизация

Пользователи системы авторизуются через OAuth 2 Яндекса по регистронезависимому email.

Отдельный OpenAPI-контракт не нужен. Необходимо подключить Swagger и добавить его URL в исключения авторизации.
