# логирование методов бэка через аннотацию
Требуется разработать функционал для логирования методов в бэке
 - функционал логирования добавляется к классу через добавление аннотации LogPublicMethods на класс 
 - логируются все публичные методы аннотированного класса. услоыий по пакету нет
 - на старте метода выводим "DEBUG" текст "<CLASS_NAME>:<METHOD_NAME>() Started >>>" 
 - при завершении метода эксепгеном выводим "ERROR" текст "<CLASS_NAME>:<METHOD_NAME>() ERROR <exception> <<<" с распечаткой стека   
 - при обычном завершении метода"DEBUG" текст "<CLASS_NAME>:<METHOD_NAME>() Done <<<"
 - класс логирования и аннотацию находится в package <MODULE_ROOT_PACKAGE>.utils.logaspect

# логирование REST Контроллеров
  аннотация LogPublicMethods должны быть назначена на все контроллеры проекта
