Правила по работе с таблицами бад данных бэкенда

 - таблицы БД при создании добавляются в файл миграции
 - JPA классы для таблиц имеют окончания "Entity". JPA Классы  кладуться в pakage *.hql.model
 - для JPA класса создается класс JpaRepository и кладется в pakage *.hql.repository
 - классы JpaRepository имеют окончание Repository
 - при выходе ответов из транзакции JPA классы конвертятся в DTO. 
 - DTO классы для JPA лежат в папке  *.dto.repository
 - DTO классы для JPA имеют окончание Dto
 - классы для конвертации JPА модели в DTO и обратно имеют суффикс Mapper и располагаются pakage *.hql.mapper
